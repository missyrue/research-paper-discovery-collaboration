# Report Contribution: MySQL 8

MySQL is the relational source of truth for user and paper records. The schema normalizes authors and paper-author ordering, models collections and bookmarks, and stores interests, research groups, memberships, and discussions. Primary/foreign keys, unique and check constraints, and indexes protect data integrity and support common lookups. Query examples use bound parameters; bookmark writes are idempotent using `ON DUPLICATE KEY UPDATE`.

The app's keyword-search route reads the seeded MySQL paper library. The local setup was verified against MySQL 8.4.9: `/api/health` reported `connected`, and the `papers` table contained 3 records. Additional runnable MySQL 8 evaluation examples are maintained once in the repository at `../../../database/mysql/advanced_concepts_demo.sql`; they explicitly show JOIN, GROUP BY with COUNT, correlated/nested subqueries, UPDATE, DELETE, and trigger audit behavior. The UPDATE and DELETE examples roll back. Their supporting objects are defined in `../../../database/mysql/advanced_concepts.sql` and installed by `database/mysql/setup-local.ps1`. These procedures and the engagement view are database examples; the app currently uses FULLTEXT search but does not call those procedures or the view. See `../../../database/mysql/ADVANCED_CONCEPTS.md` for setup instructions.
